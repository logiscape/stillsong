One-line: the standard Stillsong button — use `primary` for the single committing action on a screen, `secondary` for everything else.

```jsx
<Button variant="primary" size="lg" icon="wand-sparkles">Create My Song</Button>
<Button variant="secondary">Try again</Button>
<Button variant="quiet">details</Button>
```

Variants: primary (brass fill, dark label), secondary (matte surface + hairline), ghost (chrome actions), quiet (inline text link, no box), danger (clay, two-step deletes only). Copy is sentence case, verb-first, never shouty.
