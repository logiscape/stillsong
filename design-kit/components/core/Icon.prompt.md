One-line: Lucide icon as a CSS mask — inherits `currentColor`, so it tints with the text around it.

```jsx
<Icon name="play" size={22} />
<Icon name="image-plus" size={28} color="var(--brass-200)" />
```

Stillsong's icon vocabulary: `image-plus`, `play`, `pause`, `volume-2`, `volume-x`, `shuffle` (remix), `download`, `folder-open`, `pencil-line`, `trash-2`, `chevron-down`, `chevron-left`, `x`, `search`, `layers` (versions), `audio-lines` (instrumental), `check`, `triangle-alert`, `info`, `settings`, `pause-circle`.
Never pass emoji or a hand-rolled SVG where an Icon belongs.
